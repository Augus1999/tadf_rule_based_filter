This repository hosts the script of automatic rule-based filtering of [ChemBFN](https://github.com/Augus1999/bayesian-flow-network-for-chemistry) generated TADF candidates.

[main_filter.py](main_filter.py) hosts filters to do basic structure checks.

[post_filter.py](post_filter.py) further excludes non-novel structures against PubChem database and unstable structures.
